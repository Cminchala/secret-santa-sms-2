# 🎅 Secret Santa Frontend

A festive Next.js frontend for running Secret Santa gift exchanges with SMS notifications.

## Features

- 🎄 Festive Christmas theme with animated snowfall and glowing Christmas lights
- 📋 Interactive participant table (names, phone numbers, wishlists)
- 💳 Seamless Stripe checkout integration
- 🚀 Integrates with FastAPI backend (`/SendMSG`)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env.local`:
   ```bash
   NEXT_PUBLIC_API_URL=http://localhost:8000
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) to view the application.
